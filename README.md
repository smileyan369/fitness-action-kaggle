# fitness-action-kaggle

Public, minimal code/data for independent Kaggle verification of the fitness-action model.

- `notebooks/kaggle_verify_public.ipynb`: load `mmfit_bilstm_s42/best.pt`, run MM-Fit `test` split.
- `cloud_results/runs/mmfit_bilstm_s42/best.pt`: checkpoint.
- Data: release asset `kaggle_mmfit_processed.zip` (MM-Fit derived features, CC BY 4.0).

Expected: accuracy ~0.9996, macro-F1 ~0.9997.

This repository contains no raw videos and no personal information.
